# Step 6 — model layer

PRD reference: "Model layer" section. Note: v0.2 supersedes this with LiteLLM; keep the adapter interface narrow so swapping later is one file.

## Goals

- `models.yaml` registry resolution and a single `ModelAdapter` interface, with one concrete implementation. Token counts and costs normalized so observer metadata (step 10) has real numbers.

## Detailed steps

1. `src/engine/model.ts`:

   ```ts
   interface ModelAdapter {
     complete(req: {
       model: ResolvedModel;      // { provider, id, variantParams }
       temperature?: number;
       system?: string;
       prompt: string;
     }): Promise<ModelResult>;
   }
   interface ModelResult {
     text: string;
     tokensInContext: number;    // prompt tokens
     tokensTotal: number;        // prompt + completion for this call
     costUsd: number;
   }
   ```

2. Concrete adapter: use Vercel AI SDK (`ai` package) with its openrouter-compatible provider, since pi's provider layer is not importable outside pi. Wrap it entirely inside `AiSdkAdapter`; nothing else in the codebase imports `ai`.
3. Registry: `loadModels(path)` parses `models.yaml` against the step-2 schema and resolves `alias + variant → { provider, id, variantParams }`. Unknown alias or variant throws `ConfigError`.
4. Cost computation: per-model pricing table loaded from an optional `pricing:` block in models.yaml (per-million token rates). If absent, costUsd = 0. Keep it data-only.
5. API keys read from environment variables at call time (e.g. `OPENROUTER_API_KEY`); missing key throws `InfraError` (retryable per policy is pointless here — mark it non-retryable by subclassing or a flag).
6. Tests mock the adapter; no network in tests.

## Success criteria

- A node referencing `model: kimi-k3, variant: high` resolves to provider params through the registry.
- Adapter returns normalized token/cost fields.

## Tests

- Registry parse of PRD example; unknown variant/alias errors.
- Adapter interface satisfied by AiSdkAdapter (type test) and by a FakeModelAdapter used in later steps.
- Missing env key yields non-retryable error.
