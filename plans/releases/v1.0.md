# ngen-weave v1.0 release requirements

Prerequisite: plans/releases/v0.8.md complete (Postgres canonical store via v0.6; auth, roles, collaboration slice via v0.8).

## Definition

Version 1.0 is the deployed product. A stranger installs the server, opens the UI in a browser, builds a workflow, runs it with a real model, answers a human review from another machine, watches costs against a budget, and exports provenance for the run. At no point do they read ngen-weave's source. The HTTP API and Python public surface become semver-governed at this release; before it they were unstable by declaration.

## Requirements

1. **Standalone server deployment.** Our own FastAPI service is the serving path (the RunService protocol made real, grown incrementally since v0.2; the langgraph-server adapter was retired in v0.7). Deployment ships as a container image with explicit volume mounting for artifact blob stores and configurable artifact-store backends (local disk default, object-storage-ready); no multi-project deployment may depend on implicit local directories. A migration step ships alongside.
2. **Multi-project operation** under authenticated users: projects isolated, artifacts per project, budgets per project and per run.
3. **Full editor loop in the UI**: create, edit, validate, launch, supervise, pause/resume, review remotely.
4. **Provenance export** (PROV-JSON plus the single-file run JSON) working from the database-backed store.
5. **Notifications operational**: email/text plugins delivering on human-review-waiting, budget breach, failure.
6. **MCP exposure stable**: workflows callable from external hosts (pi tested end to end), AgentNode autonomy boxed and auditable through provenance records.
7. **Docs site current**: every public API surface documented; quickstart covers install-to-first-run without reading source.
8. **API contract published**: versioned, with deprecation policy stated.

## Explicitly out (post-1.0)

Distributed execution and Argo export (1.1), full team collaboration including simultaneous editing (1.2), vertical workflow packs (1.3+).

## Success criteria

The stranger test above, executed by someone who did not build ngen-weave, completed unaided in under an hour. Everything they touched worked through published interfaces only.
