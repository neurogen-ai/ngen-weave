# ngen-weave v0.7 release requirements

Status: draft
Prerequisite: plans/releases/v0.6.md complete (Postgres canonical store).

## What v0.7 adds

Consolidation before 1.0: landing the one deferred small feature and paying down debt so 1.0 is purely deployment and hardening.

## External document links

Nodes may reference externally-hosted documents (Google Docs etc.) by link. ngen-weave tracks the link, not the content; provenance and versioning of external documents belong to the external provider. Deferred from v0.5 because it is a leaf feature that never justified holding up the plugin release.

## Cleanup

Debt accumulated across v0.5–v0.7 lands here: anything the platform migration left half-migrated, docs lagging the new database surfaces, deprecations flagged for 1.0's semver freeze. Named at implementation time, not speculatively.

## Non-goals

- Scheduling/cron parity (waits for demand).
- Simultaneous editing, workspaces (1.2).
- Anything new: this version's value is subtraction.

## Success criteria

1. A node referencing an external document validates, renders in UI detail views, and appears in provenance as a link with no content claims.
2. No known-deprecated surface survives into 1.0 without an explicit decision record.
