# Step 12 — canonical example workflow and end-to-end tests

PRD reference: "Canonical examples" section; the worker example listing.

## Goals

- One real example under `examples/` matching the PRD's graph (draft → quality_gate → finalize / human_review → revision_worker loop), used by e2e tests with fake models.

## Detailed steps

1. `examples/draft-review/`:
   - `graph.yaml` — exactly the PRD's Graph configuration listing, plus max_steps 20.
   - `schemas/`: `input.json` (brief string), `output.json`, `review-input.json`, `review-output.json` (required boolean `pass`), `human-decision.json` (decision enum: approve | reject | escalate).
   - Node files: `worker-draft.md` (PRD's worker example, prompt templating `{{ input.brief }}`), `control-quality.md` (programmatic canonical example), `worker-revision.md`, `human-review.md` (routes from the PRD), `finalize` as a tiny programmatic control node that passes through (`checks: []` semantics → default pass) or a worker with a trivial schema — choose programmatic passthrough to keep examples model-free where possible. Document the choice in a comment.
   - `models.yaml` for the workers' aliases (used only if someone runs it with real keys).
2. `test/e2e/draft-review.test.ts`. Two suites:
   - **Fake-model suite** (no network): inject FakeModelAdapter producing valid drafts and `{pass:true}`; run via engine API directly; assert done status, outputs present, observer events logged.
   - **Quality-loop suite**: fake adapter returns failing draft first (`last_output_valid:false` handled by gate routing to revision), then passing; assert revision loop traversed fail edge then completed within budget.
   - **Human suite**: run reaches human_review; write `<node>.reviewed.yaml` with reject; assert resume routes to revision_worker; then approve path completes run.
   - **Observer suite**: inline cost observer with `max_cost: 0` fires immediately; assert reroute action marks node skipped and jumps correctly.
3. Validate `loom validate examples/draft-review` exits 0 in CI-style test.

## Success criteria

- Example validates clean; all e2e suites pass; example is copy-paste runnable per README quickstart.

## Tests

As listed above — these are the release tests for v0.1.
