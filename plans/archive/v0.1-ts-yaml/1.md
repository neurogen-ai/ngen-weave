# Step 1 — package scaffold

PRD reference: "CLI" section (layout), "Conventions" in 0.md.

## Goals

- Empty but runnable TypeScript package with the PRD's directory layout.
- Test runner wired up and proven with a trivial test.

## Detailed steps

1. Create `package.json` at repo root:
   - name `agent-loom`, `"type": "module"`, private, version `0.1.0`.
   - scripts: `build` → `tsc`, `test` → `vitest run`, `lint` → `tsc --noEmit`.
   - bin entry: `{ "loom": "./dist/cli/main.js" }` (the CLI itself is built in later steps; create a placeholder `src/cli/main.ts` that prints usage and exits 0).
2. Dependencies: `zod`, `yaml`, `minimatch` (not needed yet, skip), nothing else. Dev deps: `typescript`, `vitest`, `@types/node`. Deliberately no model SDKs until step 6.
3. `tsconfig.json`: strict, `NodeNext` modules, `outDir: dist`, `rootDir: src`, ES2022 target, declaration off, `skipLibCheck: true`.
4. Create directories: `src/schema/`, `src/engine/`, `src/cli/`, `test/e2e/`.
5. Add `.gitignore`: `dist/`, `node_modules/`, `.loom/runs/`.
6. Write one smoke test (`src/smoke.test.ts`) asserting `1 + 1 === 2` purely to prove vitest runs. Delete it in step 2 when real tests exist (or leave it; either is fine).
7. Verify `npm test`, `npm run lint`, and `npm run build` all pass. Run `node dist/cli/main.js` to confirm the placeholder CLI works.

## Success criteria

- `npm install && npm test && npm run build && node dist/cli/main.js` succeeds from a clean clone.

## Tests

- The vitest smoke test passes.
- Build emits `dist/cli/main.js`.

## Commits

- `chore: scaffold typescript package with strict tsconfig and vitest`

## Out of scope

- Any CLI command beyond the usage placeholder (step 11 wires real commands)
- Any Zod schema (step 2), engine code (step 5), or model deps (step 6)
- CI configuration, publishing config, monorepo tooling
