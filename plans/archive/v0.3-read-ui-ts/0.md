## Conventions every step follows

- Monorepo layout continues from v0.2: new packages are `packages/web-api` and `apps/web`. Root workspaces glob becomes `["packages/*", "apps/*"]`.
- **The browser never parses YAML or reads the filesystem.** Everything it renders comes from the web API as JSON. All parsing stays in `packages/core`.
- **One parser rule:** any code that needs workflow data calls core's existing loader/validator. `packages/web-api` contains zero YAML handling.
- Read-only is absolute. No endpoint accepts a body other than an empty one on health; no route uses POST/PUT/PATCH/DELETE; no `fs.write*` call exists anywhere under `packages/web-api` or `apps/web`. Reviewers grep for this.
- API responses are plain JSON, typed by interfaces exported from `packages/core/src/api-types.ts` (step 3). The SvelteKit app imports those types; there is no duplicated type definition.
- Styling: Tailwind utilities only, design tokens as CSS variables defined once in `apps/web/src/app.css`; light/dark are two variable sets under `.dark`. Components never hard-code colors.
- Commit style: conventional commits, one commit per "Commit" bullet.
- Test runner: vitest throughout (`apps/web` uses vitest too, via SvelteKit's vite config). Playwright is not introduced in v0.3; "e2e" in step 10 means API-level integration tests plus manual checklist.

## Rules for the implementing agent

- Do exactly what the current step says. Tempting extras are listed under each step's "Out of scope". Leave them.
- The PRD's two contractual API properties govern everything: lossless round-trip (raw bytes available alongside parsed form) and validator-gated (nothing served that failed `loom validate`, except the list endpoint reporting *that* a workflow is invalid).
- Keep server statelessness trivial: every request re-reads from disk through core. No caching layer beyond the content hash comparison the client does. A localhost viewing tool does not need a cache; add one only when profiling says so.
- If a step cannot meet its success criteria because an earlier step missed something, fix the earlier step minimally, note it in the commit message, continue.

## Global out of scope (applies to all steps)

From the PRD's Scope → Out. Reject any temptation:

- Any mutation: creating/editing workflows or nodes, writing review artifacts, launching or controlling runs.
- Live run inspection (run state, events.jsonl, checkpoints are invisible to v0.3).
- Auth, multi-user, remote deployment, HTTPS.
- LLM-generated summaries. Plain-language tab is deterministic templates only.
- Websockets, SSE, push updates. Polling only.
- Subworkflow display, parallel-execution visualization, mobile-specific layouts, i18n.
