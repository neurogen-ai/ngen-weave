# Step 6 — exporter: observers, human nodes, artifacts

PRD reference: "Execution" compilation map rows for human nodes, observer actions, artifacts block.

## Goals

- Complete the compilation map. After this step every loom construct exports with full parity; there is no documented-subset mode.

## Detailed steps

1. **Observer wrapper** (shared `_runtime.py` helper `observe(node_name, body_fn, observers)`):
   - Generated node functions delegate to the wrapper instead of containing raw bodies.
   - Wrapper builds the flat metadata object (`iterations`, `tokens_in_context`, `tokens_total`, `cost_usd`, `elapsed_ms`, `last_output_valid`) from usage data returned by the model call and a per-node counter in state.
   - Evaluates observer `when` expressions by transpiling them with the same expression transpiler as step 5's programmatic control nodes.
   - Actions:
     - `reroute` → return `Command(goto=target, update={...})` after marking the attempt skipped in state.
     - `pause` → raise `interrupt({"reason": "observer_pause", ...metadata})`.
     - `stop` → return `Command(goto=END)`.
2. **Human node** → generated function raises `interrupt()` with a payload equal to the canonical JSON review artifact (step 2 schema): `{ node, input, fields, decision }`. Resume path: the function receives the resumed value from `interrupt()` result, validates it against the output schema, evaluates the route table over it (same expression transpiler), returns `Command(goto=route_target)`.
3. **Artifacts sink**: for each `artifacts` entry, wrap the target node so that after its validated output is produced, the wrapper dumps `json.dumps(output)` to the artifact path with `{{ run_id }}` substituted. Write-behind: failure to write logs a warning to stderr but does not fail the run. Plain JSON only.
4. **Retries**: graph-level `retries:` policy wraps model calls in a retry loop (tenacity or hand-rolled — hand-rolled, ~15 lines, exponential backoff). Only `InfraError` retries; `DataError` propagates as v0.1 semantics dictate.
5. **Checkpointer wiring** (small, here, because interrupts need it to test): `graph.compile(checkpointer=SqliteSaver.from_conn_string(path))` where path comes from an env var `LOOM_DB`, default `.loom/checkpoints.sqlite`. Tests use `MemorySaver`.
6. Update snapshot tests and pytest integration:
   - Observer reroute test: cost observer fires, run continues at target node, skipped attempt recorded in state.
   - Human interrupt/resume test: invoke until interrupted, then re-invoke with resume payload via checkpointer thread config; assert routed per decision.
   - Artifact file written on node completion.

## Success criteria

- All three observer actions demonstrably work in the exported Python, not just compile.
- The full draft-review example (including human_review) runs end-to-end in pytest using interrupt/resume.

## Tests

- Snapshots: observer wrapper emission, human node emission, artifacts wrapper.
- Pytest: the three integration scenarios above plus regression of step 5 suites.

## Out of scope
