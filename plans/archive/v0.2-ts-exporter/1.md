# Step 1 — monorepo scaffold

PRD reference: "Repo layout" section; 0.md conventions.

## Goals

- Convert the single-package repo into an npm-workspace monorepo with the PRD's four packages.
- All existing v0.1 code moves, nothing is rewritten yet. Tests stay green.

## Detailed steps

1. Root `package.json`: add `"workspaces": ["packages/*"]`. Move shared dev deps (typescript, vitest, @types/node) to the root. Remove per-package duplication.
2. `packages/core`: move `src/schema`, `src/engine`, plus the loader and validator modules from v0.1's `src/`. Its `package.json` exports everything other packages need: schemas, loader, validator, evaluator, smoke runner.
3. `packages/cli`: move `src/cli` and its bin entry (`loom`). It depends on `@agent-loom/core`.
4. `packages/mcp`: empty skeleton — `package.json` named `@agent-loom/mcp`, one `src/index.ts` exporting a placeholder constant, one trivial vitest test. No MCP SDK dependency yet (step 10).
5. `packages/export-langgraph`: same shape as mcp — name `@agent-loom/export-langgraph`, placeholder export, no logic yet (steps 5–6).
6. Create top-level `langgraph/` directory with a `.gitkeep` and a README line saying it is generated by CI, do not edit.
7. Fix all imports across packages to workspace names (`@agent-loom/core`). Verify `npm install && npm test && npm run build` at root builds every package in dependency order (set `"type": "module"` everywhere; keep each package's tsconfig strict).
8. Update root README layout diagram if it shows the old flat layout.

## Success criteria

- Clean clone: `npm install && npm test && npm run build` passes with zero code changes beyond moves/imports.
- `loom validate` on the existing example workflow still works via `packages/cli`.

## Tests

- Existing v0.1 test suite passes unmodified (imports fixed only).
- Each package has a buildable entry point.

## Commits

- `chore: split into npm workspace monorepo with core/cli/mcp/export-langgraph packages`

## Out of scope

- Any new functionality in moved code (schemas change in step 2)
- Python toolchain setup, langgraph generation (step 5)
- Turborepo/nx/pnpm or any build orchestrator beyond npm workspaces
- Lint config changes, package publishing setup
