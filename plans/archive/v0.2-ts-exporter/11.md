# Step 11 — example workflow and end-to-end tests

PRD reference: whole PRD; this step is the release gate.

## Goals

- The draft-review example demonstrates every v0.2 feature and is exercised end-to-end through the canonical backend.

## Detailed steps

1. Update `examples/draft-review/`:
   - graph.yaml gains required `description:` and an `artifacts:` block writing finalize's output to `out/{{ run_id }}/report.md`.
   - Every node file gains nothing new except what validation requires (node descriptions are v0.3; do not add them).
   - Delete `models.yaml`; add project-root `models.json` with the kimi-k3 entry from the PRD.
2. Project root for the example: put `models.json` and `loom.json` (listing `examples/draft-review`) at repo root so the MCP server can serve it.
3. E2E suites (vitest, spawning a real langgraph-server against exported `langgraph/`, env-gated `LOOM_E2E=1` so CI without Python skips cleanly — CI's export.yml runs them where Python is installed):
   - Happy path: run → done, artifact file exists with valid JSON matching finalize output, events.jsonl validates.
   - Quality loop: gate fails first attempt → revision → pass → done.
   - Human review: run interrupts → resume via JSON payload approve → done; reject variant routes to revision. YAML-file resume equivalence asserted (from step 9 tests, re-run here through the CLI).
   - Observer reroute: cost observer triggers reroute mid-graph.
   - MCP: client calls draft-review tool, gets final output.
4. Update root README: quickstart covering validate → export → serve → run/resume → mcp, in that order, using only the example.

## Success criteria

- All v0.1 regression tests plus all v0.2 suites pass.
- A fresh clone needs exactly: npm install, loom export, start server (or let loom start it), loom run examples/draft-review.

## Tests

As listed above; these plus step 9's e2e are the release tests.
