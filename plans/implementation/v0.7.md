# v0.7 implementation plan

## Context

After v0.6 the platform layer is real: Postgres-backed stores with file mode as local default. Two RunService implementations still ship, a relic of the v0.2 decision to keep both while serving stabilized.

v0.7 subtracts and finishes: the langgraph-server adapter is deleted (per `releases/v0.7.md` and the PRD decision log), external document links land, and named debt gets paid before 1.0's semver freeze.

Depends on: `releases/v0.7.md`, `product/PRD.md`, and module shapes from `implementation/v0.1.md` through `implementation/v0.6.md`. Conventions inherited unchanged.

## Steps

### Step 1 — Remove the langgraph-server adapter

- Delete `LanggraphServerService`, `LanggraphServerConfig`, its MockTransport fakes, live-marked tests, and any langgraph-server-specific packaging notes from server docs.
- De-parameterize `packages/ngen-weave-server/tests/conformance/` to run against `LocalRunService` only; every assertion stays. The suite remains the executable spec of run semantics.
- Close out `plans/design/serving-evidence.md` with a final entry: why both existed, what the evidence showed, why deletion happened at v0.7.
- Verify: distribution metadata shows no langgraph-server dependency; conformance suite green.

Commit: `refactor(server): retire langgraph-server adapter`

### Step 2 — External document links

`packages/ngen-weave-core/src/ngen_weave/extdoc.py`: one pydantic model (`ExternalDoc`: provider, url, title, accessed-at); definitions serialize it through the standard JSON Schema representation with no format change. Read-model and detail views render links; provenance records reference the link with no content claims. Validation checks URL shape and provider name against a small registry of known providers, with unknown providers accepted but flagged in validation output.

Tests: storage round trip, read-model exposure, provenance record shape, UI detail rendering (web repo).

Commit: `feat(core): external document link references`

### Step 3 — Debt and deprecation sweep

Named at implementation time from a review pass over v0.5/v0.6 leftovers: half-migrated surfaces, docs lagging the database surfaces, deprecated flags to remove before 1.0 freezes semver. Each item lands with its own commit; anything that turns out to need real design work is either scoped into 1.0 explicitly or deferred past 1.0 with a decision record.

Commit series: per item.

## Definition of done

All three success criteria from `releases/v0.7.md` demonstrably pass: no shipped langgraph-server trace with green conformance suite; external docs validate, render, and export; no undocumented deprecated surface survives into 1.0.
